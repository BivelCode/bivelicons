This project follows [Semantic Versioning](https://semver.org/).

- **MAJOR** (`X.0.0`) — Breaking changes (renamed/removed icons, changed prefixes)
- **MINOR** (`0.X.0`) — New icons, new styles, new features (backward compatible)
- **PATCH** (`0.0.X`) — Bug fixes, optimizations, documentation updates
