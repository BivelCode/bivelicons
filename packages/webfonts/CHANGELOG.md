# Changelog — @bivelcode/icons

## 0.2.0

### Minor Changes

- [*] Initial public release of @bivelicons/webfonts
- Solid Rounded style with icons (prefix bi-sr)
- Brands style with official logos (prefix bi-br)
- Fully automated build pipeline (assign, lint, optimize, generate fonts)
- CSS class-based API with base class bc
- Combined stylesheet (bivelicons.css) and per-style CSS files
- WOFF2 and WOFF font formats for maximum browser coverage
- CDN support via jsDelivr and unpkg
- Cross-platform build support (Windows, macOS, Linux)
